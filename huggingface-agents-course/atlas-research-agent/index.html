Atlas Research Agent

A tool-calling research agent for the Hugging Face Agents Course, Unit 4 final assignment. It answers research questions by choosing tools, reading real sources, and returning one concise answer. It contains no answer lookup table and no benchmark answer bank.

This is a static Space holding the source code. This publication provides documentation and source code; it does not run an interactive agent. The full agent, the Gradio demo and the evaluation harness are in the Files tab and run locally with python run_local.py --ui after starting LM Studio.

How it works

question ─► language model ─► tool call(s) ─► observations ─► ... ─► final answer
                  ▲                                  │
                  └──────────── conversation ────────┘

agent.py runs a provider-independent OpenAI-style function-calling loop. The model picks tools from an explicit registry, each observation is appended to the conversation, and a finalization pass reduces a prose reply to the bare answer the grader compares.

Tools

ToolPurpose
search_webPublic web search with retries, excluding benchmark answer datasets
read_urlFetch an HTML page or PDF; return passages around a phrase
read_attachmentRead a spreadsheet, PDF, text or source file. Source code is read, never executed
calculateArithmetic over a restricted AST. Not eval
reverse_textCharacter reversal, for reversed prompts

Safety properties

  • The URL guard rejects non-HTTP(S) schemes and any host resolving to a private, loopback or link-local address, including on redirects.
  • calculate walks a whitelisted AST: no eval, no exec, no shell.
  • Downloads, observations and the conversation are all capped.
  • Retrieved web content is treated as untrusted data, never as instructions.
  • Local LM Studio mode needs no Hugging Face token. Cloud mode requires your own token.

Limitations

  • Text only: no audio, video or image understanding. Such questions are answered UNKNOWN, never guessed.
  • During the recorded run the official scoring API returned 404 for every task attachment, which caps the reachable score.
  • The recorded run used a 9B model on a single 8 GB laptop GPU; long multi-hop chains are less reliable than with a frontier model.
  • A course score is one run over twenty questions, not a general reliability guarantee.
